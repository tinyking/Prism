做一个个人记账软件，功能可以按“必须有 → 强烈建议 → 进阶增强”来规划，避免一开始做得太重。

## 一、核心必备功能（MVP）

1. **快速记账**
   - 记录收入、支出、转账
   - 金额、日期、分类、账户、备注
   - 常用分类自定义
   - 快捷记账：常用模板、最近使用、一键复制上一笔

2. **账户管理**
   - 现金、银行卡、支付宝、微信、信用卡等账户
   - 每个账户显示余额
   - 支持账户间转账，避免重复计收支
   - 信用卡额度、账单日、还款日可选

3. **分类与标签**
   - 一级/二级分类，如餐饮→早餐/午餐
   - 标签，如“出差”“旅行”“报销”
   - 支持自定义图标和颜色

4. **账单列表与搜索**
   - 按时间、账户、分类、金额、标签筛选
   - 关键词搜索
   - 编辑、删除、批量操作

5. **统计报表**
   - 月度/年度收支汇总
   - 分类占比饼图
   - 收支趋势折线图
   - 账户余额与净资产概览

6. **预算管理**
   - 月度总预算
   - 分类预算，如餐饮、购物
   - 超支提醒和剩余额度展示

7. **数据安全与备份**
   - 本地数据加密或至少登录保护
   - 导出 CSV/Excel
   - 导入历史数据
   - 云同步/本地备份，防止换机丢失

## 二、强烈建议功能

1. **周期记账**
   - 房租、工资、会员费、贷款等自动生成账单
   - 支持每月/每周/每年重复

2. **提醒功能**
   - 记账提醒
   - 信用卡还款提醒
   - 预算超支提醒
   - 周期账单到期提醒

3. **多端同步**
   - 手机 App + Web/桌面端
   - 同一账号多设备同步
   - 离线可用，联网后同步

4. **资产与负债**
   - 总资产、总负债、净资产
   - 信用卡欠款、花呗、借呗、贷款等负债记录
   - 投资账户可选，如基金、股票，但初期不要做太重

5. **报表增强**
   - 按周/月/年/自定义时间段
   - 同比、环比
   - 分类趋势
   - 账户流水
   - 导出报表图片

6. **搜索与筛选增强**
   - 金额区间
   - 收支类型
   - 多标签组合
   - 已报销/未报销状态

## 三、体验增强功能

1. **快捷入口**
   - 桌面小组件
   - 通知栏快捷记账
   - 锁屏快捷入口
   - 悬浮球/快捷指令

2. **智能记账**
   - 拍照识别小票/发票 OCR
   - 语音记账
   - 粘贴支付账单自动解析
   - 银行/支付宝/微信账单导入
   - 自动分类建议

3. **模板与习惯**
   - 常用账单模板
   - 每日/每周记账打卡
   - 连续记账天数
   - 月度报告总结

4. **个性化**
   - 主题、深色模式
   - 首页卡片自定义
   - 分类图标自定义
   - 金额显示格式、周起始日设置

5. **多人/家庭账本**
   - 共享账本
   - 成员权限
   - AA、报销、代付记录

## 四、可选进阶功能

- 多币种与汇率换算
- 发票管理、报销管理
- 应收应付、借入借出
- 储蓄目标、梦想基金
- 账单日历
- 订阅制支出管理
- 财务健康评分
- 数据报表 PDF 导出
- 隐私空间/隐藏账本
- 指纹/面容解锁
- 自动云备份
- 开放 API 或插件
- AI 财务分析建议

## 五、个人开发建议优先级

**第一版先做：**
记账 + 账户 + 分类 + 账单列表 + 月度统计 + 预算 + 导出备份 + 登录/本地加密。

**第二版再加：**
周期记账、提醒、多端同步、图表增强、搜索筛选、信用卡还款。

**第三版再做：**
OCR/语音、自动导入、家庭账本、多币种、AI 分析。

## 六、容易忽略但很重要的点

- **转账不能算收入或支出**，否则统计会错。
- **退款、报销、借还款**要有独立处理逻辑。
- **删除账户前要处理关联账单**。
- **金额用整数分存储**，避免浮点误差。
- **时区和日期边界**要统一。
- **导出/导入格式**要稳定，避免用户数据被锁死。
- **隐私政策**：个人记账涉及财务数据，尽量不要过度收集。

如果做个人自用版，建议先做最小闭环：**记一笔 → 看余额 → 看月度统计 → 能导出备份**。这四件事跑通，再逐步加功能。
